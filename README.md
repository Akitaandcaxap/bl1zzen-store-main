# Шаблон репозитория для Bl1zzen Store

Репозиторий — обычный публичный репозиторий GitHub. Магазин читает все `.apk` файлы
(в корне и в любых папках) и разбирает информацию из имени файла.

## Имя APK

```
title:Chrome;category:internet;version:1.2.3.apk
```

| поле       | обязательное | описание                                                        |
|------------|--------------|-----------------------------------------------------------------|
| `title`    | да           | название в магазине                                             |
| `category` | нет          | категория (по умолчанию `other`)                                |
| `version`  | нет          | версия, нужна для вкладки «Обновления» (по умолчанию `0`)       |
| `pkg`      | нет          | package name, например `com.android.chrome` — точное сравнение  |

Без `pkg` установленное приложение ищется по названию (label) — для надёжности лучше указывать `pkg`.
Разделитель поля и значения — `:` или `=`.

## depends.json (необязательно)

Положи в корень репозитория. Для неофициальных репозиториев достаточно имени:

```json
{ "name": "Мой репозиторий" }
```

У официальных репозиториев Bl1zzen Store внутри лежит блок `certificate` с подписью
(см. `main-repo-depends.json`) — рядом с названием такого репозитория в приложении стоит галочка.

## Добавление в приложение

Вкладка «Поиск» → «+» → вставь ссылку `https://github.com/user/repo`.
Для репозитория без подписи появится предупреждение.
